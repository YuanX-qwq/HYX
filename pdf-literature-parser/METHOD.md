# METHOD — 关键方法与创新点

本文说明本 Skill 如何解决题目的四个考察点（提得全 / 排得对 / 拆得清 / 核得回），以及相对基础 Agent 的增益与创新边界。所有结论均可由 `tests/selftest.py`（合成双栏 PDF，LaTeX 生成，两条后端链路）复现。

## 1. 关键方法

### 1.1 提得全：逐字提取 + 页眉页脚隔离 + 乱码检测

- 文本只做**空白归一化**，不做 Unicode 折叠：连字符 `-`、破折号 `–/—`、减号 `−`、希腊字母、上下标字符（² ³ ₁ ₂）原样保留。
- **页眉页脚判定**（`classify_headers_footers`）：顶部 13% / 底部 10% 区域内的行，按"跨页重复 ≥ max(2, 0.6×页数)"判定为运行页眉/页脚；跨页匹配用**包含关系**（`Journal of Synthetic Science` 与 `Vol. 12, No. 4` 在下一页合并为一行时仍能识别）；纯页码（`Page N`、数字、罗马数字）按模式+位置单独判定。页眉页脚存入 `page.header/footer`，不进入正文阅读流。
- **乱码检测**（`mojibake_ratio`）：U+FFFD 与 `(cid:N)` 占比 > 5% 的页标记 `text-degraded-mojibake`，提示用渲染图复核，而不是把乱码当正文交付。
- 脚注：底部区域 + 脚注标记（`*`、`1`、`a` 等行首标记）识别为 `footnote` 并保留 marker。

### 1.2 排得对：词级 2-D 栏检测 + band-walk 阅读顺序 + 跨栏续接

- **栏检测在词级做 2-D 覆盖分析**（`detect_columns_from_words`）：对每个 x-bin 统计"跨越该 x 的词"的 y 区间并集占全文高度的比例；比例 < 25% 的连续 x-run 即栏间隙候选。这比行/块级投影更稳：全宽标题行不会横向覆盖间隙，表格内部的单元格空隙也因"只有表格行跨越该 x"而不会被误判为栏（要求两侧各 ≥5 个紧贴间隙的词带、且两侧词 y 跨度都 ≥ 页高 30%）。
- **行按栏间隙拆分**：同一 y 带内左右栏的词被拆成两行；词流连续跨栏的行（标题、作者行）保持整行（"full"）。
- **band-walk 阅读顺序**（`band_order`）：按 y 带把块分组，带内按 `col-1 → col-2 → col-3` 排序；全宽块（标题/摘要/跨栏表格）单独成带，天然打断左右流。
- **跨栏/跨页段落续接**（`merge_continuations`）：上一块无句末标点（或连字符结尾）才可能续接；同栏内间距 < 60pt 合并；跨栏只在"上一块是栏末、下一块是另一栏首"时合并；列表标记（`1)`、`-`、`•`）开头的块绝不并入上一段——既修断裂句，又不把相邻段拼成一句。

### 1.3 拆得清：章节层级、表格网格、公式编号

- **章节层级**（`is_heading` + `_build_sections`）：编号模式（`1.`/`2.3`/`IV.`/`A.`）+ 独立命名标题（Abstract/Introduction/…/参考文献）+ 字号/粗体信号三级判定；居中的作者/日期行被显式排除；`Abstract/摘要` 定级 level 0。标题行在块分组阶段就与正文分开（分组规则见 1.4）。
- **表格**（`group_table_rows` + `table_grid_from_lines`）：题注（`Table N`/`表 N`）后的对齐行（相邻行词 x0 平均最近距离 ≤ 14pt）合并为一个 `table` 块；词按 x 聚类成列槽 → 输出 `grid`（行×列 + 空串缺格 + `column_xs` + `header_row`）。**跨页续表**：次页首表与上页末表列数相同且表头 Jaccard ≥ 0.6 时合并为同一逻辑表，`parts[]` 记录各页块 id。
- **公式与编号**（`is_display_equation`）：栏内居中（左缩进 ≥ 12%、右留白 ≥ 3%）、含数学符号或短"x = y"形态的块判为公式；行尾 `(n)`/`[n]` 紧贴栏右缘的判为公式编号并挂回公式（方程体右缘按"去掉编号后的词"计算，避免编号贴边导致误判）。上下标：PyMuPDF 路径利用 span 字体标志与字号记录 `sup` 标记，文本本身原样保留（² ³ 不丢）。

### 1.4 块分组：双峰间距阈值 + 缩进/题注/标题断块规则

行间距呈双峰分布（行内 ~2pt vs 段落/结构 ~6–20pt）。`_gap_threshold` 找排序后第一个 > 3pt 的跳变，阈值取两簇中点；无跳变（整页等距文本）用保守阈值。辅以五条断块规则：首行缩进 + 上下行都接近行尾（新段，且不会误断参考文献悬挂缩进续行）、大缩进非满行跟在满行后（表格行/居中元素开头）、大缩进行之后回到行首（公式结束）、题注行首、参考文献 `[N]` 行首；标题行前后双向断块，标题与正文永远不粘连。

### 1.5 核得回：证据锚点 + 机械核验门

- 每个块带 `id`（`p3b12` = 第 3 页第 12 块）、`page`、`bbox`、`zone`、`source`；`document.md` 在每块前打印 `[pNbM zone]` 锚点。
- 答案的每条 evidence 要求**逐字引文**。`evidence.py locate/check/verify` 用空白无关的精确子串匹配在文档模型中检索：命中→`verified`；块 id 不符→`mismatch`；找不到→`unverified`。`make_result.py` 把未核验条目自动写入 uncertainty——**引文过不了机械核验就不算事实**。
- 未报告（unreported）、无法判断（uncertainty）、材料冲突（conflict）三类分别记录，禁止把"没写"当成"写了"。

### 1.6 扫描版 / 异常处理

- 无文字层页：probe 检出 → 渲染 150dpi PNG（fitz/pdfplumber/pdftoppm 三选一）→ tesseract TSV（词级置信度进行模型）；低置信词保留原文并如实标注，不猜补。
- 加密：`needs_password` 检出 → 空口令重试 → 仍失败 `refused` 并说明原因。
- 后端链：PyMuPDF → pdfplumber → poppler `pdftotext -bbox-layout`，全部可选、缺省自动降级；无任何后端时给出明确错误，交由 Agent 使用平台 pdf-* 工具完成。

## 2. 相对基础 Agent 的增益（使用增益）

基础 Agent 直接读 PDF 文本流的典型失败：双栏串行拼接（"读到的句子是两栏交替拼的"）、行首尾换行连词、表格变散文、页眉页脚混入正文、公式符号丢失、答案无定位。本 Skill 的确定性几何层把这些问题在**进入模型之前**修掉：

- **质量增益**：栏序/段落边界/表格网格/公式编号由坐标与排版信号决定，与模型采样无关，重复运行结果一致；模型只做它擅长的理解与作答，且每条答案被引文核验门约束。
- **效率增益**：一次解析（脚本）取代逐页贴文本 + 人工找页码；`document.md` 已按阅读顺序排好，Agent 按节读取、`evidence.py` 批量定位引文，显著减少模型往返次数与校对成本（预算规划 ≤ 40 请求/案例，限额 64）。
- **可验证性**：增益可复现——同一 PDF 重复解析输出逐字节一致；自测套件（fixture + 真实 LaTeX 双栏 PDF × pymupdf/pdftotext 两条链路，24 项断言）证明"排得对/拆得清/核得回"；平台用相同案例对基础 Agent 与加载本 Skill 的 Agent 做公平对照（白板固定），本方法不依赖任何对具体案例的定制。

## 3. 创新点与边界（创新增益）

| 创新点 | 相对现有解析方案的价值 |
|---|---|
| 词级 2-D 覆盖栏检测 + 紧贴间隙词带校验 | 不依赖 PDF 制作者标记；全宽标题/跨栏表格不会破坏检测；表格内空隙不误判为栏 |
| 行按栏间隙拆分 + 连续词流桥接判定 | 同一 y 带的左右栏词正确分行，标题/作者等居中行不被拦腰截断 |
| 双峰间距阈值 + 缩进/题注/标题/参考文献断块规则 | 处理 LaTeX 类"无段间空距、仅首行缩进"的版式，同时保护悬挂缩进与列表 |
| 跨页续表按列数+表头相似度自动合并（parts[] 溯源） | 表格跨页后仍是一条可处理的结构，且每页留锚点 |
| 页眉页脚跨页"包含关系"匹配 | 页眉因分栏在下一页合并成一行时仍能识别，不混入正文 |
| 公式编号按栏右缘挂接、方程体去编号算留白 | 双栏论文里 `(n)` 贴栏右缘也能正确归属 |
| 证据机械核验门（quote→块逐字命中） | 把"回到原文证据"从口头承诺变成可执行的校验；未命中自动降级为不确定性 |

**边界（如实声明）**：本方法按结构元素识别图表与公式，**不解释其科学含义**（符合题面）；依赖文字层或 OCR；跨栏巨型表格按栏拆分输出；合并单元格以空串缺格 + bbox 佐证，不猜测合并关系；海报式/版式高度异构的文档栏检测可能降级为单栏（warnings 说明）；公式不生成 LaTeX 重建（按题面"保真"要求输出原文字符，需要时可由 Agent 用 `latex-compiler` 复核重排）。

## 4. 可靠性设计（可靠体验）

- 调用触发：SKILL.md 的 description 覆盖中英文触发词；工作流 0–5 步自包含，任何一步失败都有下一动作。
- 稳定性：全部确定性算法，无随机、无网络依赖；自测套件覆盖双栏/单栏、页眉页脚、表格、公式、参考文献、续接、乱码标记；两后端交叉验证同一合成 PDF。
- 异常矩阵：加密、无文字层、OCR 失败、图片表格、乱码、页码错乱、跨页续表，逐项有识别手段与处置动作（见 SKILL.md 异常处理矩阵）。

## 5. 生态复用

- 脚本互相独立、可单独调用（probe → parse → evidence → make_result），输入输出均为文件，适合编排进任何 Agent 工作流；JSON Schema 随包提供。
- 自测无需网络：fixture 15 项零依赖必跑；真实 PDF 9 项在"有 LaTeX + 任一侧后端"时自动附加。
- 样例（examples/）全部标注 `synthetic`，不冒充正式案例结果；正式案例产物由评测平台固定提供，本包不含任何预写答案。
