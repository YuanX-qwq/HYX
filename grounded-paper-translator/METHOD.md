# METHOD — 术语锁定、段落锚定与机械核验

## 1. 要解决的问题

科研文献翻译的失败通常不是“句子不通顺”，而是四类可复核性缺陷：

| 缺陷 | 典型表现 | 后果 |
|---|---|---|
| 术语漂移 | 同一术语在摘要/正文/图注中三种译法 | 读者无法判断是否同一概念 |
| 段落错位/漏译 | 双栏串栏、跨页断段、长文分批时丢段 | 结论缺前提，引用对不上 |
| 关系失真 | 数字、单位、引用编号、否定与限定被改写 | 事实错误且难以发现 |
| 不可核验 | 只有一段“看起来像全文”的中文 | 无法定位、无法抽查、无法复用 |

因此本 Skill 的目标不是“译得像”，而是**译得可复核**：每个段落有稳定 id 和页码锚点，每个术语受文件化术语表约束，每处数值/引用/否定由脚本核对。

## 2. 流水线设计

### 2.1 版面解析与阅读顺序（`pdfwords.py` + `layout.py`）

1. **取行**：PyMuPDF → pdfplumber → `pdftotext -bbox-layout` 依次降级；每行保留文本、bbox、字号、粗体、旋转标记。行内 span 按字符间距决定是否补空格（PDF 常把每个单词切成独立 span）。
2. **XY-cut 阅读顺序**：对行框做递归“最宽空隙”切分——先找被所有行跨越的纵向空白（分栏），再找横向空白（分块）。跨栏的标题/摘要会阻止整页的纵向切分，因此被先横向切出，双栏正文不会被交错。
3. **段落重建**：同一叶节点内按行合并，判据为字号变化、粗体变化、首行缩进、句末标点、行距倍数；跨叶只在“上一段未以句末标点结束且下一段同栏”时合并；跨页续段在中间页无正文（如图版页）且上段未收句时合并。
4. **行末连字符**：用全文词表判定——`dimension-`/`ality` 合为 `dimensionality`，`condensed-matter` 这类真实复合词保留连字符。
5. **结构分类**：`title/authors/abstract/heading/body/caption/table/equation/reference/footnote/figure-label/header/footer/margin/fragment`。页眉页脚、页码、arXiv 水印、旋转文本、图像区域内的文字（`figure-label`）不进入正文，也不参与翻译。

产物 `segments.json` 的每个段落单元包含 `pid`（P0001…）、`page`、`bbox`、`zone`、`section`、`kind`、`text`、`sentences`。pid 由页序与阅读顺序确定，同一文件同一后端重复运行结果一致。

### 2.2 术语抽取与锁定（`gloss.py`）

- **候选**：缩写（`CNN`、`t-SNE`）、首字母大写多词短语（`Monte Carlo`、`order parameter`）、种子词表命中（`resources/glossary.seed.csv`），按频次排序并去掉被长词条支配的短词条。
- **锁定**：`glossary.csv` 必须给出 `term_en → term_zh`；脚本检查空译名、重复英文词条、两名共享同一译名，通过后写 `glossary.lock.json`（`locked: true`）。
- **为什么文件化**：提示词里的“请保持术语一致”无法被验证；文件化后 `verify.py` 可以对每个词条统计“出现段数 / 合规段数”，给出可复核的一致率与违规段号。

### 2.3 人工/模型翻译（`translations.jsonl`）

翻译单元是段落，不是句子也不是章节：段内有公式时保留公式记号，用中文叙述衔接；不合并相邻段，保证 pid 与原文一一对应。每行可带 `notes`（术语与句式决策）和 `uncertainty`（不确定标注）。

### 2.4 机械核验（`verify.py`）

| 检查项 | 规则 | 严重度 |
|---|---|---|
| coverage | `scope.pids` 每段恰有一条非空译文；多出/缺失/重复均报 | FAIL |
| numbers | 数字多重集（含科学计数、百分比、范围）逐项比对 | FAIL |
| units | `%`、`eV`、`nm`、`µL`、`kcal` 等词元比对（带词边界） | WARN |
| citations | `[12]` `[1, 7]` `[3–5]` 与 `(Author, 2019)` 原样保留 | FAIL/WARN |
| cross_refs | `Figure 3 → 图 3`、`Table I → 表 I`、`Eq. (A1) → 式 (A1)` 编号一致 | FAIL |
| symbols | 希腊字母与数学符号（∑ ∫ ≈ ≤ ∞ σ ϵ）不得丢失 | WARN |
| negation | 原文有否定而译文无否定词 → FAIL；译文凭空加否定 → WARN | FAIL/WARN |
| hedging | may/might/suggest/approximately 等情态与限定被硬化 | WARN |
| glossary | 锁定词条出现处必须使用锁定译名（含 variants） | FAIL |
| length | 译文字符/原文词数 < 0.7 或 > 3.8 | FAIL/WARN |
| sentences | 译文句数 < 原文 55% | WARN |
| untranslated | 译文与原文完全相同、或拉丁字母占比 > 0.55 | FAIL/WARN |
| placeholder | 使用 `[待确认]`/TODO 但未在 `uncertainty` 说明 | WARN |

统计量：覆盖率、术语一致率（合规出现数/总出现数）、FAIL/WARN 计数、平均长度比。

### 2.5 组装（`assemble.py`）

`result.json` 同时包含：段落级双语对照与锚点、锁定术语表、核验摘要、指标、scope、证据（pid/page/bbox/引文前缀）、不确定项、来源哈希与变更记录；`output_contract` 中声明的字段一并覆盖，无法填写者置 `null` 并说明。

## 3. 实测（真实论文，非示例）

论文：Carrasquilla & Melko, *Machine learning phases of matter*, arXiv:1605.01735v1（18 页，双栏图版与附录，含公式、图表、参考文献）。

| 指标 | 实测值 |
|---|---|
| 页数 / 行数 | 18 页；1101 行 |
| 段落单元 | 118（正文 30、图注 9、标题/摘要/小标题 6、脚注 1；公式 16、参考文献 4、图内文字 16、页眉页脚 22、其他 9） |
| 翻译范围 | 43 段（标题、摘要、正文、图注、小标题、脚注），4832 词 |
| 覆盖率 | 43/43 = 100% |
| 锁定术语 | 37 条，一致率 37/37 = 100%（按出现段计 100%） |
| 核验结果 | FAIL 0，WARN 3（2 条公式行的句数启发式、1 条“是否”类否定启发式） |
| 输出 | `result.json`、`bilingual.md`（43 段）、`bilingual.csv`、`glossary.csv`、`verify_report.json` |

复现命令与产物见 `demo/README.md`；`tests/selftest.py` 用合成样例覆盖负例（丢数字、丢否定、术语漂移、缺段、引用改号、未翻译照抄），并可用 `--real-pdf` 重跑真实 PDF 的切分统计。

## 4. 与“提示词式翻译”的对比协议

公平对照应在**同一篇文献、同一模型、同一范围**下进行，比较可机械计算的三项：

1. **术语一致率**：同一术语在不同段落使用同一译名的比例。对照条件不给术语表、不做回扫；本 Skill 条件先抽表锁定再翻译。两者都用同一段号口径统计。
2. **长文完整率**：`scope.pids` 中被翻译且非空的段数占比（含跨页/跨栏段是否漏译）。
3. **事实保留率**：数字、单位、引用、图表编号、否定关系五类核验通过率（对照条件的译文同样用 `verify.py` 检查，以保证口径一致）。

本目录的 `demo/` 与 `tests/` 提供了可重复的度量入口；平台固定案例的对照由平台统一组织，参赛者不自造白板或正式答案。

### 4.1 本会话实测（6 段对照）

在同一模型、同一原文、同一 6 段（`P0007/P0021/P0037/P0042/P0077/P0106`）上做了一次真实对照：

| 条件 | 术语一致率 | FAIL | WARN |
|---|---|---|---|
| 单遍直译（不查术语表、不做自检） | 27/32 = **84.4%** | 10 | 1 |
| 本 Skill（锁 37 条术语 → 逐段译 → verify 返修至 FAIL=0） | 32/32 = **100%** | 0 | 1 |

对照组出现 6 个术语漂移（`Monte Carlo`→“蒙特卡罗”、`hidden layer`→“隐层”、`accuracy`→“精度”、
`feed-forward neural network` 未用“前馈神经网络”、`training set`/`neural network` 段内不一致），另有 1 条否定 FAIL。
两组的数字、单位、引用均未出现 FAIL——这说明**本对照的增益集中在术语一致性与否定关系**，不应夸大为全面质量提升。
数据与明细见 `demo/ablation.json` 与 `demo/ablation.md`。

## 5. 已知限制

1. 版面解析是启发式：极端版式（跨页巨型表格、旋转整页、三栏+边注）可能仍需人工核对，脚本会给出 `layout-risk` 提示。
2. 句数/长度/否定/情态检查是启发式，`WARN` 允许人工放行；`FAIL` 必须修复或进 `uncertainty`。
3. 术语译名质量取决于译者领域知识；脚本只保证一致性，不保证“最佳译名”。
4. 显示公式只保留记号，不重排公式结构；矩阵类公式在 PDF 抽取顺序下可能呈线性串行（`notes` 中标注）。
5. 参考文献保留原文，不翻译作者、刊名与编号。
