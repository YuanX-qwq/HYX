# 语域与最小编辑规则（按目标文体）

## 通用最小编辑原则
1. 只改语言层：语法、句法、搭配、标点、用词、连贯性；不改结论、不加数据、不删限定。
2. 一次只解决一类问题，避免整段重写导致无法逐条复核。
3. 术语全篇统一：同一概念只用一种写法；缩写首次出现 = 全称（缩写）。
4. 数字、单位、引用编号、图表与公式指向逐字保留；单位大小写按领域惯例统一（如 mL、°C）。

## 各文体

| 文体 | 允许 | 避免 |
|---|---|---|
| 期刊论文（journal） | 被动与主动混用、客观陈述、过去时叙述实验 | 宣传化副词（very/remarkably）、绝对化（always/never/prove）、口语连接词 |
| 学位论文（thesis） | 章节衔接句、已知/本文工作的时态区分 | 与章节无关的综述式铺陈、第一人称过度 |
| 基金申请（grant） | 明确的必要性、可行性与风险说明 | 空泛承诺、无依据的“国际领先” |
| 审稿回复（review reply） | 逐条回应、礼貌但直接、引用修改位置 | 争辩式语气、模糊承诺 |
| 英文摘要（abstract） | 一句话背景 + 方法 + 关键数字 + 结论 | 引用编号、图表编号、未解释缩写 |

## 中式英语与直译腔高频问题
- 冗余名词化：the improvement of the efficiency → improved efficiency。
- 主语错位：In this paper, we found... 与 The results show... 混用；一段内统一。
- 连接词滥用：Moreover/Furthermore/In addition 连用；按真实逻辑关系选择。
- 冠词与单复数：a equipment、researches、data is/are。
- 介词搭配：in 25 °C → at 25 °C；experiment on/for 区分。

## 限定强度对照（改写时禁止跨级）
- 弱：may / might / could / suggest / indicate / 可能 / 提示
- 中：show / find / observe / 表明
- 强：demonstrate / prove / confirm / always / 证明 / 必然
只允许同级别内替换；跨级必须由作者确认并写入 `unresolved`。
