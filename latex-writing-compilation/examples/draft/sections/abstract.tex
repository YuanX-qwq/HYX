\begin{abstract}
Property prediction for amorphous polymers is limited by long-range electrostatic
interactions that message-passing networks truncate after a few hops. We present
SAGN, a sparse-attention graph network that routes messages along a learned
$k$-nearest neighbour sparsification of the molecular graph while retaining full
electrostatic context through a low-rank attention branch. On the public
118k-polymer benchmark under scaffold splits, SAGN reduces MAE by 1.33\,K over a
strong GIN baseline at comparable parameter count. We report full configuration,
split protocol and build recipe so that every number in this paper can be
regenerated from the released source.
\end{abstract}
